# Catering Shop (ASP.NET Core MVC + SQL Server LocalDB)

Requires .NET 9 SDK and SQL Server LocalDB (comes with Visual Studio / SQL Server Express).

    cd CateringMvc
    dotnet run

Open http://localhost:5080. The database `CateringShopDb` is created automatically on first run.
Connection string: CateringMvc/appsettings.json
